# Submitting to G-ExtensionStore

1. Fork https://github.com/sirjonasxx/G-ExtensionStore (branch `repo/1.5.3` or current base).
2. Copy everything from `store-submission/Room Backup/` into `store/extensions/Room Backup/` in your fork:
   - `extension.zip`
   - `extension.json`
   - `icon.png` (40x40)
   - `screenshot.png`
3. Open a Pull Request into the store base branch.

Do not obfuscate the jar. Packet names only (already the case).
